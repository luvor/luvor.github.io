Public portfolio of Islambek Chynybekov.

- Live portfolio: [luvor.github.io](https://luvor.github.io/)
- Personal site and recommendations: [chynybekov.com](https://chynybekov.com/)
- LinkedIn: [linkedin.com/in/luvor](https://www.linkedin.com/in/luvor/)
- GitHub: [github.com/luvor](https://github.com/luvor)

The portfolio focuses on verified product work: Tripmaxx, BENI, REDTEU, and ÖZGER. It separates personal ownership, shared delivery, live surfaces, and experiments. NDA names, internal metrics, customer data, and the legacy private CV are not part of the public build.

## Local checks

```bash
npm ci
npm run build
```

The build writes the deployable static site to `_site/`. The Playwright suite covers desktop, mobile, accessibility, interactions, and public release paths; it requires the pinned browsers from `playwright install`.
