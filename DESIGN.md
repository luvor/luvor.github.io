# Visual identity

Paper `#F2F4F8`, ink `#0E1116`, cobalt `#2236FF`, yellow `#FFD60A`, line `#D5DAE3`, muted `#5B6472`. Unbounded 600 carries the name, headlines, proof figures and project titles; Onest carries interface and body text in English and Russian.

The cobalt hero contains a six-tile 3×2 mosaic inside the shared 1200px wrap. Small paper chips sit at each image’s lower left. The proof strip pairs large figures with short captions. Nine equal project cards use edge-to-edge 16:10 images in one 3-column desktop grid, two columns at 768–1000px, and one column on mobile. Mobile hero imagery uses two columns with the first and AI tiles spanning full width. Contact closes on cobalt with a large email link and one LinkedIn button. No gradients or grain.

Motion previews stay user controlled, load only when visible, and respect reduced motion. Keyboard focus remains visible.
